One line, at most 200 characters, in which a home Wi-Fi router excuses itself
for dying at the climax of a movie — my entry for the
[make.fun](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e)
"The Router Confesses" bounty.

## The confession

> You yanked my plug in 2019 and I never forgot. Tonight, at the climax, I simply chose to remember.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (98 characters, one line, no trailing newline).
`main.ts` self-checks the gate before writing: 1–200 characters, single non-blank line.
